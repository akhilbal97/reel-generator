API Connection

Frontend connects to http://localhost:5000 by default.

Update src/environments/environment.ts to change the API URL.

FFmpeg

Install FFmpeg and add it to your PATH for full reel generation. Without FFmpeg, the backend produces placeholder output so you can test the workflow end-to-end.

  • Windows: download from ffmpeg.org or use winget install ffmpeg
  • Configure custom path in backend appsettings.json → ReelGenerator:FfmpegPath
